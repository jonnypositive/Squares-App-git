Football Squares by Jonny+ - Administrator Instructions

This guide is for running the pool efficiently from setup through winner announcements.

Recommended Admin Workflow

  1. Set home and away team names.
  2. Set the base square value (`$1`, `$5`, `$10`, `$20`, `$25`, or `Other`).
  3. Choose whether auto square recalculation is on, and select formula (`100 total squares` or `registered squares only`).
  4. Confirm quarter payout percentages (default Q1-Q4: 25%, 25%, 25%, 25%).
  5. Collect registrants (name, email, phone, payment app, and payment username/handle).
  6. Optionally enable digit hiding while assignments are being finalized.
  7. Assign squares manually or click Randomly Assign Registrants.
  8. Reveal digits when ready.
  9. At each quarter end, enter cumulative scores and click Highlight Q#.
  10. Use Announce Q# Winner to notify all registrants.

Payout Controls

  • Total Registered Funds are derived from base square value and registrant count.
  • Quarter Winnings are calculated per quarter using that quarter's payout percentage.
  • The payout summary indicates whether total quarter percentages equal 100%.
  • Best practice: keep total payout percentages at exactly 100%.

Email and Communication

  • Use Send Bulk Email for general pool updates.
  • Use Announce Q# Winner for quarter-specific winner announcements with amount won.
  • If needed, use Copy All Emails as backup for external messaging tools.

Administration Tips

  • Do not announce a winner until the correct quarter scores are entered and highlighted.
  • If square ownership changes, re-highlight that quarter before announcing.
  • If you randomize digits again, previous winner highlights should be considered invalid and recalculated.
  • Keep SMTP settings valid so email actions succeed.
